# itch.io Release Guide

Use the archive at `releases/neon-apex-racing-itchio.zip`.

## Recommended itch.io settings

- Project type: `HTML`
- Kind of game: `HTML5`
- Upload the ZIP and mark it as `This file will be played in the browser`
- Launch file: `index.html`
- Embed size: `1600 x 900`
- Enable fullscreen button: `Yes`
- Mobile friendly: `Yes`

## Store Page Copy

Short description:
`Neon Apex Racing is a high-style browser arcade racer with boost, drift bias, traffic dodging, a day-night cycle, and mobile touch controls.`

Suggested tags:
`Racing`, `Arcade`, `Retro`, `Synthwave`, `Score Attack`, `HTML5`, `Singleplayer`

## Upload Checklist

- `index.html` is at the root of the ZIP
- All asset references are relative
- Desktop and mobile sanity checks passed locally
- Include `screenshots/desktop-preview.png` and `screenshots/mobile-preview.png` on the itch.io page
